# Back-end da Concessionária 🚗

Backend de um sistema para gerenciamento de clientes e veículos, desenvolvido com Java e Spring Boot.

---

## 🚀 Funcionalidades

- Cadastro de veículos
- Cadastro de clientes
- Atualização de dados
- Exclusão de registros
- API REST

---

## 🛠 Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- MySQL
- JPA / Hibernate

---

## 📚 Objetivo do projeto

Projeto desenvolvido com foco em aprendizado de desenvolvimento backend utilizando Java e Spring Boot para construção de APIs REST.
